Configurar partida

Selecciona un granjero, escribe tu nombre y el código si vas a unirte a una sala existente. Si dejas el código vacío, crearás una nueva sala. Elije sabiamente tu granjero, cada uno tiene distintas cantidades de casillas para hundir. ¡El granjero más astuto gana!

Tip: Si compartes el código con tu equipo, podrán unirse al instante.
